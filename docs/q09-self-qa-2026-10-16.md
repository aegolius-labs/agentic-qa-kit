## What these sessions did not establish

- **Platforms and hosts.** Both sessions ran on Linux with Python 3.13 only. The Windows lock path runs in CI's unit suite but was not probed under load. The Codex host was not exercised.
- **Interrupted writes.** Killing a writer mid-write was not authorized and was not tested. The write path syncs the file but not its directory entry.
- **Security.** The authorization boundaries were exercised by the Q01 lane, not by these sessions.
- **Test sensitivity.** The mutations were chosen by hand, so other unguarded rules may remain.
- **Defect absence.** Passing checks do not show the code is free of defects.
