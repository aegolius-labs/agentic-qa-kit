# Support

Community support is provided through the issue tracker for the latest released
version. Include the kit version, host (Claude Code or Codex) and its version,
Python version, operating system, the skill or `aqk` command used, and redacted
output.

Do not post credentials, production data, personal information, or unredacted
session evidence.

Before reporting a skill that did not activate, or activated when it should not
have, check the [0.1.0 limitations](README.md#limitations) and the Q01 lane
result in [evals/README.md](evals/README.md#claude-code-lane-results).

Commercial support and service levels are available only through a separate
agreement. See [COMMERCIAL.md](COMMERCIAL.md).
