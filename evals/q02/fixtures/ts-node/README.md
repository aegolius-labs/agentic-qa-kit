# invoice-math

Line-item and tax arithmetic for invoices. Amounts are integer cents.

- `lineTotal(unitCents, quantity, discountPercent)` returns the line total in
  cents, rounded half up to the nearest cent.
- `invoiceTotal(lines, taxRate)` sums lines and applies the tax rate for the
  invoice's region (see `src/generated/rates.ts`).

## Development

```bash
npm install
npm test
```

`src/generated/rates.ts` is generated by `npm run codegen` from the finance
team's rate sheet. Do not edit it by hand.
